1. Arsitektur Teknologi (Tech Stack)Untuk menjaga performa tetap ringan namun terlihat modern, kita akan menggunakan:Frontend: HTML5, Tailwind CSS (untuk desain modern & responsif), dan JavaScript (Vanilla/AOS Library untuk animasi).Backend/Database: Google Sheets API via Google Apps Script (sebagai jembatan data).Hosting: GitHub Pages (Gratis dan stabil).2. Struktur Navigasi & KontenWeb akan dibagi menjadi beberapa bagian utama dalam satu halaman (Single Page Application):BagianKonten UtamaHero SectionFoto landscape kelas, Nama Kelas, dan Slogan (misal: "The Future of Networking").Tentang KamiDeskripsi singkat visi, misi, dan sejarah terbentuknya kelas X TKJ.Struktur OrganisasiBagan interaktif: Wali Kelas, Ketua Kelas, Sekretaris, Bendahara.Daftar SiswaTabel/Grid yang datanya diambil otomatis dari Google Sheets.Galeri KegiatanFoto-foto praktikum, olahraga, atau momen kebersamaan.Kontak & Media SosialLink Instagram kelas dan lokasi SMKN 2 Marabahan.3. Alur Integrasi Data (Google Sheets to Web)Agar data siswa (Nama, NISN, Jabatan) bisa muncul di web, alurnya adalah:Google Sheets: Simpan data siswa di sini.Google Apps Script: Buat fungsi doGet() untuk mengubah data tabel menjadi format JSON.Fetch API: Di file script.js web Anda, panggil URL Apps Script tersebut untuk menampilkan data secara otomatis.4. Konsep Desain (UI/UX)Agar terlihat profesional, gunakan palet warna yang melambangkan teknologi dan identitas sekolah:Warna Utama: Biru Navy (Teknologi) dan Putih/Abu-abu Terang (Bersih).Tipografi: Gunakan font Sans Serif seperti Inter atau Roboto.Fitur Tambahan:Dark Mode Toggle.Search Bar di bagian daftar siswa.Animasi scroll menggunakan AOS (Animate On Scroll).5. Langkah Pengembangan (Roadmap)Tahap 1: Persiapan DataBuat Spreadsheet dengan kolom: Nama, Jabatan, Foto_URL, Media_Sosial.Tulis kode Google Apps Script sederhana untuk membagikan data tersebut sebagai API.Tahap 2: Coding FrontendMembuat struktur HTML dan menyusun layout dengan Tailwind CSS.Menghubungkan JavaScript untuk menarik data dari Spreadsheet.Tahap 3: DeploymentUpload kode ke repositori GitHub.Aktifkan fitur GitHub Pages di menu Settings.
